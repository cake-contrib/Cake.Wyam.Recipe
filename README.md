# Cake.Wyam.Recipe

> [!IMPORTANT]
> **This recipe is no longer maintained and the repository will be archived.**
>
> Cake.Wyam.Recipe wraps the [`Cake.Wyam`](https://www.nuget.org/packages/Cake.Wyam)
> addin, which targets the [Wyam](https://wyam.io/) static-site
> generator. Wyam was discontinued years ago — its successor is
> [Statiq](https://statiq.dev/) — and Cake itself has already removed
> Wyam-based documentation generation from
> [Cake.Recipe](https://github.com/cake-contrib/Cake.Recipe). With the
> underlying ecosystem retired, this recipe has no working role to
> play.
>
> Existing consumers can continue to use the published NuGet package
> on legacy versions, but no further releases are planned and the
> repository will be archived once this notice is merged. New build
> scripts that need a documentation pipeline should look at
> [Statiq](https://statiq.dev/) directly, or at whatever modern
> doc-generation flow Cake.Recipe converges on next.
